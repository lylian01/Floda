# Floda
Quản lý web bán hoa
Floda là một ứng dụng web quản lý bán hoa được xây dựng bằng nhiều công nghệ full-stack, bao gồm JavaScript, HTML, CSS và C# (ASP.NET). Dự án áp dụng một số Design Pattern cơ bản để tổ chức mã nguồn một cách rõ ràng và dễ mở rộng, nhằm hỗ trợ các chức năng quản lý sản phẩm hoa, xử lý giao dịch và hiển thị giao diện thân thiện với người dùng.

Frontend: JavaScript, HTML, CSS
Backend: C#, ASP.NET
